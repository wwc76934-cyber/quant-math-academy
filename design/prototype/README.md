# Quant Math Academy — 视觉原型说明

这是 Phase 1 的**静态设计参考**，不是生产代码。目的是在 AGY 实现 React 应用之前，用真实教材内容确定：

- 三栏阅读布局与正文版心
- 中文 serif + KaTeX 的排版气质
- 定义/定理/证明/例题/注记的视觉层级
- D/P 标注、先修、相关、量化应用在右栏的组织
- 首页与完整目录的信息密度
- 浅色/深色主题
- 390px 移动端的阅读与操作

## 给 AGY 的实现提示

1. **不要照抄 HTML 结构。** 生产实现用 React 组件 + 设计 token；`styles.css` 只作为视觉基准。
2. **正文版心 720px、字号 18px、行高 1.9** 是阅读页的核心；不要为了塞更多内容压缩。
3. **环境块用边框/底色/标签区分，不用彩色卡片。** 定理是浅底 + 3px 左线；定义是 2px 左线；证明是虚线；例题是上横线。
4. **D/P 徽标**：P0 实心、P1 描边、P2/P3 渐弱；D 用 5 个墨点，不用颜色。
5. **右栏信息层级**：本页目录 → 本节信息 → 先修 → 相关 → 应用 → 为什么这样标注。
6. **移动端**：单栏、标题 30px、正文 17px、底部三按钮（标记/上一节/下一节）、目录与本节信息进抽屉。
7. **深色**：暖黑 `#131312`，不要纯黑；定理左边线可改为 `--ink-secondary` 降低亮度。
8. **字体**：Phase 1 用系统 Noto Serif SC / Noto Sans SC；不要打包 17MB 字体。

## 已知缺口

- 移动端目录抽屉和右栏 sheet 只有设计说明，原型未实现交互。
- 主题切换按钮是静态的；深色版本是独立页面。
- 首页统计、进度、路径数据是示意值，不是真实计算结果。
- 34 章中只有 C01/C08/C11/C33 计划标注；其余显示“标注完善中”。
- 阅读页只放了 11.4 的节选，用于验证排版，不是完整章节。

## 设计判断

- 采用“学术出版社 + 现代技术文档”的中间路线：serif 正文、sans UI、暖纸底、朱砂强调。
- 拒绝渐变、玻璃拟态、彩色卡片、emoji 图标；用细线、留白、字重建立层级。
- 数学公式是主角：公式容器不设背景，编号右对齐，长公式横向滚动。
- 标注系统不抢正文：右栏小字、徽标克制、理由可展开。
