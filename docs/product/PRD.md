## 1. 决策摘要

Quant Math Academy（量化数学学院）不是一个“把 PDF 搬到网页上”的阅读器，而是一套**以一部真实、严谨的中文数学教材为唯一内容源**的个人学习系统。

首版做出三个明确取舍：

1. **静态优先，不做后端。** 网站构建为纯静态站点，学习数据保存在浏览器本地，支持 JSON 导入导出。首版不建账号、不做云同步、不做服务端数据库。
2. **阅读是主战场，标注是差异化。** 首版把全部工程预算投入到“读得进去、找得到、知道该不该学”三件事上；练习、复习、可视化按阶段推进，不用功能数量冒充产品质量。
3. **标注必须可解释、可校正。** 难度（D1–D5）与必要性（P0–P3）分离，逐知识点人工策展，保留判定理由与复核状态；禁止按标题关键词批量打标。

技术基线：Vite + React + TypeScript，构建期把 Markdown 预渲染为结构化 HTML（KaTeX 预渲染），客户端只负责阅读交互、检索与本地学习状态。内容源继续以 `src/chapters` 与 `src/solutions` 为唯一权威，网站不复制、不改写正文。

## 2. 背景与问题

### 2.1 现有资产

《量化数学进阶教材》已定稿：

- 8 篇、34 章，正文与习题解析分离；
- 约 157 万字符（1,574,815 字符），构建版 PDF 1,964 页；
- 889 个正式数学环境：199 定义、270 定理、12 引理、71 命题、9 推论、236 例题、91 注记、1 公理；
- 3,276 个独立公式、813 个编号公式、约 29,000 个正文行内公式；全书 lint 共 48,148 条公式、0 错误；
- 698 道习题与 698 份解析一一对应；
- 严格定义—定理—证明—例题—习题体系，含量化金融应用；
- 内容为中文，公式为 LaTeX，源文件为结构化 Markdown。

这套资产的内容质量足以支撑一个真正的学习产品，问题不在内容本身，而在**使用方式**。

### 2.2 五个真实痛点

| 编号 | 痛点 | 具体表现 | 产品回应 |
|---|---|---|---|
| P1 | 学习负担重 | 一千多页，不知道先学什么、哪些可跳过 | 难度/必要性双轴标注 + 学习路径 + 今日建议 |
| P2 | 阅读体验差 | PDF 导航弱、公式缩放差、长文疲劳 | 三栏阅读、专业数学排版、主题与版式个性化 |
| P3 | 进度不可见 | 不知道自己学到哪、掌握了多少 | 显式学习状态 + 分篇/优先级进度面板 |
| P4 | 路线不匹配目标 | 实习冲刺与系统进阶需求不同 | 三种路径 + 自由探索，只改推荐不改内容 |
| P5 | 学练分离 | 习题与正文割裂，错题难复习 | 章内练习、解析折叠、错题本、间隔复习 |

### 2.3 非目标

- 不做通用课程平台（不支持上传课程、不做多教材商城）。
- 不做 PDF 阅读器换皮（不以“翻页”为核心交互）。
- 不在首版做 AI 问答、AI 讲解、自动出题。
- 不做社交、排行榜、多人协作。
- 不擅自修改教材学术内容。

## 3. 用户与场景

### 3.1 主要用户

**用户 A：实习冲刺者（首要）**
数学基础尚可，2–4 个月内参加量化研究实习笔试/面试。时间碎片化，需要知道“哪些是 P0、哪些今天可以跳过”，并通过高频题型检验。

**用户 B：系统进阶者**
研究生或高年级本科生，希望按教材体系完整学习，重视证明与理论深度，有较长的学习周期。

**用户 C：研究应用者**
已有数学基础，围绕因子、组合、时序、风险等实际问题上溯数学工具，以检索和补基础为主。

**用户 D：教材作者/维护者**
需要持续校订内容、补充章节、检查公式与引用，不希望网站与源文件脱节。

### 3.2 核心场景

1. **每天打开：** 首页直接给出“继续上次阅读 / 今日下一个知识点 / 待复习”，不需要重新找位置。
2. **判断优先级：** 在目录中按 P0/P1 过滤，或在阅读页右栏看到难度、必要性、预计时间、先修与高频标记。
3. **深读一节：** 三栏阅读，公式清晰，定理/证明/例题层级分明，可折叠证明先自行推导。
4. **学完即练：** 章末习题逐题展开解析，标记掌握/错题，进入复习队列。
5. **按目标学习：** 选择“实习冲刺”路径，按周获得 P0/P1 的推荐顺序，而不是被要求读完 1,964 页。
6. **快速定位：** 搜索“协方差矩阵”，直接跳到定义、相关定理、习题与应用，并看到先修知识。
7. **长期积累：** 笔记、公式收藏、错题与学习记录可导出，不被平台锁定。

## 4. 产品定位与设计原则

### 4.1 一句话定位

> 一部严谨中文量化数学教材的现代学习界面：知道今天学什么，知道为什么学，知道学到哪。

### 4.2 产品属性优先级

1. 数字教材（内容完整、公式准确）
2. 系统学习平台（路径、状态、复习）
3. 考核训练平台（P0/P1、高频考点、习题）
4. 个人知识管理工具（笔记、收藏、导出）

### 4.3 设计原则

1. **内容完整性高于一切。** 任何转换都不得丢公式、改符号、断证明、错配习题。网站正文必须可追溯到源文件的具体行。
2. **阅读优先。** 阅读页不做营销、不做推荐流、不做打断式弹窗；辅助信息收进右栏，可按需隐藏。
3. **标注服务于决策。** 每个 D/P 标签回答“难不难/该不该现在学”，必须附理由；没有依据的标签宁可不标。
4. **状态由用户确认。** 滚动、停留、打开页面都不等于掌握；学习状态必须显式设置。
5. **路径是建议，不是门禁。** 任何章节都可直接访问；路径只改变推荐顺序与提示，不裁剪原文。
6. **本地数据可迁移。** 首版无账号，但导出文件必须包含完整、可读、可再导入的学习数据。
7. **克制的视觉。** 学术气质来自字体、留白、层级与细节，不来自渐变色、玻璃拟态和装饰性动画。
8. **渐进增强。** 无 JavaScript 时至少可读正文；图表、动画、复杂交互失败时不影响阅读与公式。

## 5. 成功标准与指标

### 5.1 产品成功标准（验收导向）

一个准备量化实习的学习者，在本网站学习同一章节的体验，必须显著优于阅读 PDF：

- 3 次点击内从首页到达任意知识点；
- 阅读页首屏 1.5 秒内出现正文（本地构建、无网络请求阻塞）；
- 任一公式可复制 LaTeX，任一环境可复制链接；
- 目录、搜索、先修跳转不中断阅读；
- 移动端可完成“阅读—标记—练习—复习”完整闭环；
- 关闭浏览器后，学习状态、笔记、错题不丢失；
- 内容覆盖率 100%，公式错误 0，习题解析匹配 100%。

### 5.2 个人学习指标（产品内展示，不上报）

- 总覆盖率：已学习+已掌握 / 全部知识点；
- 核心覆盖率：P0+P1 已掌握 / P0+P1 总数；
- 本周完成知识点数、练习数、复习完成率；
- 连续学习天数（可选，不做惩罚性提醒）；
- 待复习队列长度。

### 5.3 工程指标

- 构建期 KaTeX 失败数 = 0；
- 正文文本覆盖率 = 100%（空白归一化后逐节比对）；
- 习题↔解析匹配率 = 100%；
- 桌面端 Lighthouse Performance ≥ 90、Accessibility ≥ 95（Phase 5 验收）；
- 首屏 JS ≤ 250KB gzip（不含按章懒加载内容），单章数据 ≤ 400KB gzip；
- 所有关键页面在 360px、768px、1024px、1440px 四档宽度无横向溢出。

## 6. 核心概念

| 概念 | 定义 | 粒度 |
|---|---|---|
| Part 篇 | 教材的 8 个大部分 | 8 个 |
| Chapter 章 | 34 章 | 34 个 |
| Section 节 | `## x.y` 一级节 | 219 个，作为**知识点（KP）** |
| Subsection 小节 | `### x.y.z` | 仅用于页内导航，不单独设学习状态 |
| Environment 环境 | 定义/定理/引理/命题/推论/例/注记 | 约 1,300 个，作为可链接锚点 |
| Proof 证明 | 附属于定理类环境 | 可折叠 |
| Equation 公式 | 带 `\tag{x.n}` 的独立公式 | 约 850 个编号公式 |
| Exercise 习题 | 章末编号题 | 每章 16–28 题 |
| Solution 解析 | 与习题一一对应 | 独立文件 |
| Learning Path 学习路径 | 知识点有序集合 + 节奏建议 | 3 条 + 自由模式 |
| Learning State 学习状态 | 用户对 KP 的显式判断 | 5 态 |

**关键决策：知识点粒度取“一级节”，不取“每个定义/定理”。** 一级节是教材天然的讲授单元（通常 2,000–8,000 字），适合 30–90 分钟的学习与复习调度；定义/定理作为节内锚点，支持深链、搜索与笔记，但不单独承担进度状态。这样既避免 1,300 个状态点造成管理负担，也保留精确跳转能力。

## 7. 功能需求

优先级：M = Phase 1 必须；S = Phase 2/3 应该；C = Phase 4 可选。

### F1 阅读体验（M）

- F1.1 三栏布局：左目录、中正文、右辅助信息；≥1280px 三栏，1024–1279px 两栏（右栏折叠为抽屉），<1024px 单栏。
- F1.2 左侧目录：8 篇 34 章完整目录，逐层展开；当前位置高亮；章/节完成状态点；支持折叠整栏。
- F1.3 中间正文：正文宽度 30–40em 可调；中文正文 serif，UI sans；段落、标题、列表、表格、引用块完整呈现。
- F1.4 数学排版：KaTeX 预渲染；行内/独立公式、多行对齐、矩阵、分段函数、公式编号、`\tag` 编号；公式横向溢出时容器内滚动，不撑破布局。
- F1.5 环境排版：定义、定理、引理、命题、推论、例、注记、证明、解在视觉上可区分但不花哨；环境编号可锚定、可复制链接。
- F1.6 右侧栏：本页目录、难度、必要性、预计时间、先修、相关知识点、量化应用、高频标记、快速练习入口。
- F1.7 阅读个性化：浅色/深色/跟随系统；字号 4 档；阅读宽度 3 档；证明默认展开/折叠；专注模式（隐藏左右栏）；目录折叠。
- F1.8 阅读记录：自动保存最近章节、节与滚动位置；首页“继续阅读”；不把滚动等同于掌握。
- F1.9 分享与复制：复制章节链接、环境链接、公式 LaTeX、代码块；复制成功有轻量反馈。
- F1.10 键盘：`[`/`]` 上一节/下一节，`f` 专注模式，`t` 主题，`/` 搜索，`?` 快捷键帮助；输入框内不触发。
- F1.11 移动端：目录抽屉、正文单栏、右栏信息折叠为“本节信息”面板；公式可横向滚动；底部固定“上一节/下一节/标记”。

### F2 难度与必要性标注（M）

- F2.1 难度五级 D1–D5，定义见 `CONTENT_MODEL.md`；必要性四级 P0–P3；二者独立，不合并成单一“星级”。
- F2.2 每个 KP 的标注包含：难度、必要性、预计学习时间、先修 KP、相关知识、标签、量化应用、高频考查标记、学习目标、判定理由、复核状态。
- F2.3 标注在目录、阅读页右栏、路径页一致展示；支持按 P0/P1、D 等级过滤目录。
- F2.4 标注可追溯：UI 提供“为什么这样标注”折叠说明；数据文件含 `rationale`、`reviewedBy`、`reviewedAt`。
- F2.5 首批只标注 4 个试点章（C01/C08/C11/C33），其余章显示“标注完善中”，不生成无依据标签。
- F2.6 提供标注校验脚本：枚举合法、先修存在、无自环、试点章全覆盖、P0/P1 比例合理（用于发现异常，不强制配额）。

### F3 学习路径（S，Phase 3）

- F3.1 路径 A 量化实习冲刺：只推荐 P0/P1，优先概率统计、线性代数、数学推理与高频考点；明确跳过非必要高级证明；给出 6 周节奏。
- F3.2 路径 B 系统数学进阶：按教材顺序覆盖全部 KP，保留证明与理论深度；给出约 22 周节奏。
- F3.3 路径 C 量化研究应用：以应用簇（因子、组合、时序、风险、定价）为入口，按先修闭包补基础；给出约 15 周节奏。
- F3.4 路径 D 自由探索：不设顺序，保留目录与搜索。
- F3.5 同一时间只有一个“当前路径”；切换路径不删除学习记录；路径页展示已完成/总数、本周计划、下一项。
- F3.6 路径只改变推荐与排序，不隐藏、不删减任何正文。

### F4 习题与解析（M 基础版，S 完整版）

- F4.1 章末习题逐题渲染，题号、题干、公式、列表完整；解析默认折叠。
- F4.2 每题操作：展开解析、标记已掌握、加入错题本、收藏、重新练习。
- F4.3 解析与题目一一对应；解析区独立展示，不混入正文。
- F4.4 错题本按章/时间/标签筛选；支持移出与重做。
- F4.5 答案判定：首版采用**自评**（我做对了/做错了/看了解析），不做字符串匹配；若后续引入数值/表达式判定，必须使用符号计算或结构化答案，且明确标注“机器判定”。
- F4.6 习题搜索：按题干关键词、知识点、章过滤（Phase 2 搜索上线后）。

### F5 学习进度与复习（S，Phase 3）

- F5.1 学习状态五态：未开始、学习中、已学习、已掌握、需要复习；用户显式切换，任意状态可回退。
- F5.2 面板：总进度、分篇进度、P0/P1 掌握率、已完成习题、错题数、最近学习、当前路径、待复习。
- F5.3 复习： Leitner 式 5 盒（1/3/7/21/45 天）；用户对复习结果选择“忘记/模糊/记得”，据此升降盒；可手动提前/推迟；算法规则在 UI 中可解释。
- F5.4 复习队列按到期日排序；显示来源（已学习/已掌握/错题）。
- F5.5 数据本地持久化，schema 版本化；支持导出/导入 JSON；导入前校验版本与结构，提供合并/覆盖选择（Phase 3 可先只做覆盖+备份）。
- F5.6 数据面板显示最近保存时间与存储占用；提供“清空数据”二次确认。

### F6 检索与关联（S，Phase 2）

- F6.1 全文搜索：章节标题、节标题、定义/定理标题与正文、例题、习题、解析、应用关键词。
- F6.2 中文分词 + 英文术语别名：如 期望/expectation/mean、特征值/eigenvalue、协方差/covariance；别名表人工维护。
- F6.3 结果分组与过滤：全部/知识点/定义定理/例题/习题/解析；显示章、节、命中片段、类型徽标。
- F6.4 键盘操作：上下选择、Enter 跳转、Esc 关闭；最近搜索。
- F6.5 知识关联：每个 KP 展示先修（必须有向无环）、相关（人工策展）、被引用；跳转不丢失当前位置。
- F6.6 知识图谱：Phase 4 评估，仅在依赖数据准确且可导航时上线；不做纯装饰性关系图。

### F7 交互式学习（C，Phase 4）

- F7.1 分步推导：仅对选定的 10–15 个关键推导提供逐步展开；每步含说明；数据与正文分离，禁止改写原文。
- F7.2 可视化：正态分布、CLT、Bayes 更新、矩阵变换、特征值、梯度下降、有效前沿、布朗运动等；每个组件必须标注数学假设、参数含义与对应公式，模型与图表一致。
- F7.3 可视化按需加载，移动端可操作，不以动画牺牲性能；无 JS 时显示静态说明与公式。
- F7.4 笔记：KP 级 Markdown 笔记、公式收藏、章节笔记；自动保存；导出 Markdown/JSON。
- F7.5 学习建议：基于路径、状态与复习队列的规则式建议，可解释；不调用外部 AI。

### F8 内容维护（M 工程能力）

- F8.1 内容构建脚本：从 `src/` 生成站点数据，校验失败阻断构建。
- F8.2 新增章节流程：放入源文件 → 更新章节目录 → 运行构建 → 校验通过 → 自动出现在目录。
- F8.3 内容变更审计：记录源文件哈希；构建产物含源路径；页面提供“查看源文件”入口（开发模式）。
- F8.4 数学公式错误、引用缺失、习题解析不匹配均使构建失败（或明确警告并列出）。

### F9 开源与部署（Phase 6，需用户确认）

- F9.1 代码与内容分离授权：代码可采用 MIT；教材内容默认不随代码仓库公开，除非用户明确确认权利与许可。

- F9.3 第三方依赖、字体、图片、参考资源的许可证审计。
- F9.4 未经用户明确确认，不创建公开仓库、不发布站点。

## 8. 学习模式的规则化定义

## 9. 非功能需求

### 9.1 性能

- 首屏不加载全部章节数据；章节数据按路由懒加载。
- 数学公式在构建期渲染为 HTML，客户端不引入 KaTeX 运行时（仅保留 CSS 与字体）。
- 搜索索引分片/懒加载，首屏不加载全量索引。
- 图片/可视化使用现代格式与尺寸约束；首版无图片。
- 长章节（C08 约 98KB 源文）滚动流畅，目录高亮使用 IntersectionObserver 节流。

### 9.2 可访问性

- 语义化 HTML：`nav`、`main`、`article`、`aside`、`h1–h4`。
- 键盘可达；焦点可见；跳转链接；ARIA 标注图标按钮。
- 对比度：正文 ≥ 7:1（浅色），次要文本 ≥ 4.5:1；暗色同等。
- 尊重 `prefers-reduced-motion`；动画可关闭。
- 公式提供 MathML（KaTeX 默认输出）或 `aria-label` 原文，屏幕阅读器可读。

### 9.3 数据安全

- 所有学习数据仅存本地 `localStorage`；不上传。
- 导出文件含 schema 版本、导出时间、校验和；导入前备份当前数据。
- 清空/覆盖需二次确认。
- 不在 URL 中放置笔记内容或个人信息。

### 9.4 兼容性

- 现代 Chromium/Firefox/Safari 最近两个大版本；不支持 IE。
- 移动端 iOS Safari、Android Chrome 可完成核心闭环。
- 打印样式：阅读页可打印为干净讲义（隐藏导航，保留公式与环境）。

### 9.5 内容与版权

- 教材正文保持原样；网站不内置未经授权的第三方教材、题库或图片。
- 字体优先使用系统字体；若打包开源字体，必须记录许可证与子集化范围。
- 开源前单独审计内容再分发权利；代码许可证与内容许可证分开。

## 10. 范围边界

### 10.1 首版明确不做

- 用户账号、云同步、多设备实时同步。
- 服务端数据库、API、管理后台。
- AI 问答/讲解/自动批改。
- 社区、评论、排行榜。
- 多教材、课程售卖、支付。
- 原生 App。
- 复杂知识图谱可视化。

### 10.2 技术债边界

- 首版只支持本教材的 Markdown 方言；若未来接入第二本书，再抽象内容适配层。
- 首版搜索为客户端索引；全文规模预计 < 10MB，可接受。
- 首版笔记为纯文本 Markdown，不做富文本编辑器。

## 13. 开放问题（Phase 1 前需定）

1. 中文正文最终字体：系统宋体栈 vs 子集化 Noto Serif SC。Phase 1 先用系统栈，Phase 5 评估字体包体积与观感。
2. 公式复制交互：点击公式复制 LaTeX，是否需要“复制为 MathML/图片”作为次要菜单。Phase 1 先做 LaTeX。
3. 阅读进度与学习状态的边界：滚动只记位置；进入“学习中”是否自动？决定：首次打开某节 30 秒后提示“标记为学习中”，但不自动改“已学习/已掌握”。
4. 标注的“高频考查”依据：由教材内容与量化实习常识判断，需在理由中写明，不伪造公司真题来源。
5. 开源内容范围：待 Phase 6 由用户确认；代码可开源，正文默认不公开。
