# Quant Math Academy 信息架构与交互规范

- 版本：v1.0
- 配套：`PRD.md`、`../design/DESIGN_SYSTEM.md`
- 目的：固定站点结构、路由、页面职责、导航规则、状态与数据流，作为 Phase 1 实现依据。

---

## 1. 站点地图

```
/                              首页（今日学习 / 继续阅读）
/syllabus                      完整教材目录（8 篇 34 章）
/learn/:chapterId              阅读页（章级路由，节锚点）
  #c11-s4                      一级节锚点
  #c11-thm-11.3                定理/定义等环境锚点
/paths                         学习路径总览
/paths/:mode                   A/B/C 路径详情（a=冲刺, b=系统, c=应用）
/practice                      练习总览（按章 / 错题 / 收藏）
/practice/:chapterId           章内练习
/progress                      学习进度与数据管理
/search?q=                     搜索结果
/review                        复习队列（Phase 3）
/notes                         笔记与收藏（Phase 3）
/about                         关于、许可与数据说明（Phase 6）
*                              404
```

设计决策：

- **阅读页以“章”为路由单位，以“节/环境”为锚点。** 不把每个知识点做成独立页面，避免破坏连续阅读；深链通过 hash 直达，滚动定位。
- **搜索是独立页面**，不是弹出层；首页与顶栏可唤起，结果为可分享 URL。
- **设置不单独成页**，主题、字号、宽度在阅读页工具条与全局菜单中；数据导入导出放在 `/progress` 底部。
- **Phase 1 只实现 `/`、`/syllabus`、`/learn/:chapterId`；** 其余路由显示“建设中”占位，但导航结构先定，避免后期返工。

## 2. 全局导航

### 2.1 顶栏（所有页面）

高度 56px，sticky，底部 1px 分隔线，背景与页面同色（不使用强模糊/玻璃效果）。

| 区域 | 内容 | 行为 |
|---|---|---|
| 左 | 标识：`量化数学学院` + 小字 `Quant Math Academy` | 点击回首页 |
| 中 | 教材 / 学习路径 / 练习 / 学习进度 | 当前项下方 2px 强调线；键盘可达 |
| 右 | 搜索按钮（放大镜 + “搜索” + `⌘K`/`Ctrl K`）、主题切换、更多菜单 | 搜索打开 `/search` 并聚焦输入框 |

移动端（<900px）：

- 左侧仅保留标识缩写“量化数学”；
- 主导航收进汉堡菜单（全屏抽屉，分组列出）；
- 搜索变为图标；主题切换保留；
- 底部可选“阅读/练习/进度”三项快捷栏，仅在阅读相关页面出现。

### 2.2 阅读页子导航

在顶栏下方，高度 44px，sticky：

- 左：`教材 / 第 11 章` 面包屑；章节标题（单行省略）。
- 中：本章阅读进度条（细线，不抢视觉）。
- 右：字号、宽度、专注模式、上/下一章。
- 移动端：只保留返回目录、章标题与“Aa”按钮；其余进抽屉。

### 2.3 页脚

仅在首页、目录、路径、进度、关于页出现。内容：

- 数据仅保存在本机 · 导出于 2026-11-08（动态日期）；
- 教材内容版权说明链接；
- 开源信息（Phase 6 前不显示仓库链接）。

阅读页不显示页脚，避免打断。

## 3. 页面规格

### 3.1 首页 `/`

**目标：** 回答“今天学什么”，在 5 秒内让用户开始或继续学习。

结构（自上而下）：

1. **刊头**：产品名（serif，48–56px）、一句定位、教材规模（8 篇 / 34 章 / 219 节 / 48,148 公式）。右上角可显示当前路径与周次。
2. **继续学习**（主卡片，宽度优先）：
   - 有记录：章号、节号与标题、上次位置、章进度、按钮“继续阅读”；
   - 无记录：显示“从第一篇开始”与“选择学习路径”两个入口。
3. **今日面板**（三列，移动端纵向）：
   - 下一个知识点：路径推荐 + D/P + 预计分钟 + 开始；
   - 待复习：到期数量 + 进入复习；
   - 今日练习：推荐章 + 未做题数。
4. **学习路径**：A/B/C 三张卡片，显示目标、周期、KP 数、当前是否激活。
5. **全书地图**：8 篇列表，每篇显示章数、已学/总数、P0 完成度；点击进入目录对应位置。
6. **数据说明**：一行小字，说明本地保存与导出位置。

空状态：首次访问时“继续学习”替换为“三步开始”引导（选目标 → 看路径 → 读第一节），不弹窗、不强制注册。

### 3.2 目录 `/syllabus`

**目标：** 一屏看清全书结构，快速判断优先级并进入阅读。

布局（≥1100px）：

- 左侧 200px：8 篇索引（粘性），显示篇号、篇名、进度环/百分比；点击滚动到对应篇。
- 右侧主区：篇标题 + 章列表；每章为可展开行。

章行：

```
第 11 章  期望、方差、矩与概率不等式        D3 · P0 · 6 节 · 约 5.5h   [展开]
```

展开后显示节列表：

```
11.1  期望的定义与性质            D2  P0  45min   ○ 未开始
11.2  方差、矩与分布形态          D3  P0  60min   ◐ 学习中
...
```

交互：

- 顶部工具条：搜索本章/全书（Phase 2 全量）、筛选（必要性 P0/P1/P2/P3；难度 D1–D5；状态）、“只看未学”。
- 章节行点击标题进入 `/learn/c11`；节行点击进入 `/learn/c11#c11-s1`。
- 展开/折叠状态保存在本地；默认展开当前阅读章。
- 未接入标注的章显示“标注完善中”，不显示伪造 D/P。
- 目录必须包含 34 章全部条目；Phase 1 即使某章内容尚未 QA，也保留条目并标注状态。

移动端：篇索引变为顶部横向 chips；章列表单列；筛选进抽屉。

### 3.3 阅读页 `/learn/:chapterId`

**目标：** 长时间、低干扰、数学准确的深读。

三栏（≥1280px）：

| 栏 | 宽度 | 内容 |
|---|---|---|
| 左 | 264px | 全书目录树（篇→章→节）；当前节高亮；章完成状态；底部“目录/搜索” |
| 中 | 自适应，正文 34em | 章首、节、环境、例题、习题、解析 |
| 右 | 272px | 本页目录、本节信息、先修/相关、操作 |

中栏结构：

1. **章首**：章号（大字 serif）、章标题、导言、阅读时长与节数；右上“标记本章已学”不提供（避免误操作），只有节级状态。
2. **节**：`h2` 带节号；节首可有“学习目标”一行（来自元数据，若已标注）；正文。
3. **环境**：按类型呈现；证明可折叠；例题与解视觉关联；公式编号右对齐。
4. **节尾操作条**：`标记为学习中 / 已学习 / 已掌握 / 需要复习`；上一节 / 下一节；添加笔记（Phase 3 前禁用并说明）。
5. **本章小结**：作为特殊节，不设学习状态。
6. **习题**：题卡列表；解析折叠；操作按钮。
7. **章尾**：上一章 / 下一章；返回目录。

右栏：

- **本页目录**：`##` 与 `###` 层级，滚动高亮；点击平滑滚动并更新 hash。
- **本节信息**：D/P 徽标、预计时间、高频标记、学习目标、标签。
- **先修知识**：列表，显示用户状态；未掌握时提示“建议先补”。
- **相关知识点**：人工策展，最多 6 条。
- **量化应用**：短列表，指向正文中的相关段落（若可定位）。
- **操作**：标记状态、加入复习、复制链接（Phase 1 先做复制链接与状态）。

移动端：

- 单栏；顶部有“目录”和“本节信息”两个抽屉按钮；
- 正文 100% 宽，左右 padding 20px；
- 公式容器可横向滚动；
- 底部固定操作栏：目录 / 上一节 / 下一节 / 标记；滚动时自动隐藏，向上滚动出现；
- 右栏信息进入底部 sheet，不挤压正文。

阅读行为：

- 滚动位置按节记录（节 ID + 节内偏移百分比），节流 500ms；
- 首次进入某节 30 秒后，若状态为“未开始”，顶部出现一条非模态提示“标记为学习中？”，可关闭且本会话不再提示；
- 不自动标记“已学习/已掌握”；
- 通过 hash 进入时，滚动到锚点并高亮 1.5 秒；锚点不存在时回退到章首并提示。

### 3.4 学习路径 `/paths` 与 `/paths/:mode`

总览：

- 三张路径卡（A/B/C）+ 自由模式入口；
- 每张卡：目标人群、周期、每周投入、KP 数、P0 覆盖、当前进度、按钮“查看路线 / 设为当前”。

详情：

- 顶部：路径名、目标、周期、总 KP、已完成、预计完成日期（基于每周投入，可解释）。
- 周计划：时间线/表格式，按周分组；每周显示主题、KP 列表、预计时长、完成状态。
- 每项：节号、标题、D/P、分钟、状态；点击进入阅读页。
- 规则说明折叠区：为什么这样排序（先修闭包、P0/P1 规则）。
- 切换路径：确认对话框说明“不会删除学习记录，只改变推荐顺序”。

Phase 1 只做路径介绍页与静态路线预览？PRD 将路径放在 Phase 3；Phase 1 首页可展示路径卡但点击显示“Phase 3 开放”。为避免“假功能”，Phase 1 路径入口显示“即将开放”并说明，不做不可用按钮。

### 3.5 练习 `/practice` 与 `/practice/:chapterId`

总览：

- 三个入口：按章练习、错题本、收藏题；
- 统计：已做题数、正确自评率（基于自评，注明）、错题数；
- 章列表：题数、已做、错题。

章内练习：

- 顶部：章名、题数、筛选（全部/未做/做错/收藏）、进度。
- 题卡：题号、题干（公式完整）、操作（展开解析/标记做对/做错/收藏）；解析展开后显示完整解析与“加入错题本”。
- 分页或虚拟列表：每章 ≤28 题，不需要分页。
- 键盘：`j/k` 上下题，`Enter` 展开解析（可选）。

Phase 1：只读展示 + 解析折叠；状态按钮禁用并标注“Phase 3 开放”。不伪装已完成功能。

### 3.6 进度 `/progress`

- 头部统计：总覆盖率、P0/P1 掌握率、已学 KP、已掌握 KP、练习数、错题数、待复习。
- 分篇进度：8 条横向条形，显示已学/总数与 P0 完成。
- 难度分布：D1–D5 已掌握数量（堆叠条或小表，不用雷达图）。
- 最近活动：最近 10 条（时间、章节、动作）。
- 复习队列：到期/未来 7 天（Phase 3）。
- 数据管理：最后保存时间、导出 JSON、导入 JSON、清空（二次确认）、schema 版本。
- 空状态：解释“打开页面不等于掌握”，引导标记第一节。

### 3.7 搜索 `/search`

- 顶部大搜索框，自动聚焦；下方筛选 chips：全部/知识点/定义定理/例题/习题/解析。
- 结果列表：类型徽标、章·节、标题、命中片段（高亮）、D/P（若有）。
- 左侧可选分面：篇、章、难度、必要性；移动端折叠。
- 空结果：建议同义词、检查错别字、浏览目录。
- 搜索历史（本地，最多 10 条）；`Esc` 清空焦点，`Enter` 打开首条。
- 结果 URL 可分享（`?q=...&type=...`）。

### 3.8 复习 `/review`

- 队列卡片：一次一张；正面显示节标题、所属章、上次复习、盒子等级；按钮“显示要点”。
- 背面：学习目标、核心公式（来自元数据/正文锚点）、笔记入口、“忘记/模糊/记得”。
- 会话结束：统计本次复习数、升降盒分布、下一批到期时间。
- 可跳过、退出；退出保留当前进度。

### 3.9 笔记 `/notes`（Phase 3/4）

- 左：按章分组的知识点列表，带笔记数量；
- 右：选中 KP 的笔记编辑器（Markdown，纯文本，预览切换）；
- 顶部：导出全部笔记（Markdown/JSON）、搜索笔记；
- 自动保存 800ms 防抖；显示保存状态。

### 3.10 404

- 一句话 + 返回首页/目录；不显示无意义插画。

## 4. 导航与 URL 规则

- 章 ID：`c01`–`c34`；节 ID：`c11-s4`；环境 ID：`c11-thm-11.3`；习题：`c11-ex-1`。
- 阅读页 URL：`/learn/c11#c11-s4`；环境深链：`/learn/c11#c11-thm-11.3`。
- 章节切换保留阅读偏好；不保留滚动位置（新章从顶部开始）。
- 浏览器后退应返回上一阅读位置（依赖 hash/history）；实现时使用 `history.replaceState` 更新 hash，避免污染历史栈。
- 外部链接在新标签打开，站内链接同标签。
- 所有可分享链接必须有稳定的 `og:` 标题/描述（Phase 5 可选）。

## 5. 状态与数据流

### 5.1 学习状态机

```
unseen ──打开/手动──> learning ──手动──> learned ──手动──> mastered
   ↑                      │                 │                │
   └────────手动重置───────┴─────────────────┴────────────────┘
learned/mastered ──到期或手动──> needs_review ──复习“记得”──> learned
needs_review ──复习“忘记”──> learning
```

规则：

- 只有用户操作能改变状态；阅读滚动、停留、搜索点击都不改变。
- “已学习”= 读完并理解基本内容；“已掌握”= 能独立完成相关习题/复述要点。UI 在状态菜单中给出这句话。
- 复习升降盒独立于状态；`needs_review` 可由复习排期自动进入（Phase 3），也可手动。
- 状态变更写入活动日志（最近 200 条，超出滚动删除）。

### 5.2 数据存储

单一根对象，避免多 key 不一致：

```ts
type StoreV1 = {
  schemaVersion: 1;
  updatedAt: string;
  settings: { theme; fontSize; measure; focus; proofDefault; reduceMotion };
  progress: Record<SectionId, {
    status: 'unseen'|'learning'|'learned'|'mastered'|'needs_review';
    lastReadAt?: string;
    scrollOffset?: number;
    statusChangedAt?: string;
  }>;
  lastLocation?: { chapterId; sectionId; at };
  exercises: Record<ExerciseId, {
    result?: 'correct'|'wrong'|'viewed';
    bookmarked?: boolean;
    inMistakes?: boolean;
    attempts: number;
    updatedAt: string;
  }>;
  notes: Record<SectionId, { markdown: string; updatedAt: string }>;
  bookmarks: { sections: SectionId[]; formulas: FormulaId[] };
  review: Record<SectionId, { box: 0|1|2|3|4; dueAt: string; lastReviewedAt?: string }>;
  path: { active: 'a'|'b'|'c'|'free'; startedAt?: string };
  activity: Array<{ at: string; type: string; targetId: string; detail?: string }>;
};
```

存储键：`qma:store:v1`。写入防抖 400ms；页面隐藏/卸载时同步写入。

### 5.3 构建期数据流

```
src/chapters/*.md ─┐
src/solutions/*.md ─┼─> tools/content/parse-book.mjs ─> content/generated/*.json
content/metadata/** ─┘                                      │
                                                            v
                                          web build (Vite) 生成静态 HTML/JS
                                                            │
                                                            v
                                                  浏览器 localStorage
```

- 章节正文数据与元数据分离；元数据缺失时页面仍可读，只是不显示 D/P。
- 搜索索引在构建期生成，按章分片，客户端按需加载。
- 公式在构建期渲染，产物含 KaTeX HTML；客户端只加载 `katex.min.css` 与字体。

## 6. 响应式断点

| 断点 | 宽度 | 布局 |
|---|---|---|
| Mobile | < 640px | 单栏；抽屉导航；底部操作栏 |
| Tablet | 640–1023px | 单栏正文 + 可折叠目录；右栏信息进 sheet |
| Laptop | 1024–1279px | 左目录 + 正文；右栏折叠为按钮/抽屉 |
| Desktop | 1280–1599px | 三栏（264 / 正文 / 272） |
| Wide | ≥1600px | 三栏 + 更大留白；正文不超过 40em |

正文最小宽度 320px；代码/公式容器 `overflow-x:auto`；表格外层可滚动；不允许整页横向滚动。

## 7. 无障碍与键盘

- 跳过导航链接（Skip to content）。
- 目录树使用 `<nav aria-label="教材目录">`；当前项 `aria-current="page"`。
- 环境使用 `<section aria-labelledby>`；公式容器 `role="math"` 由 KaTeX 输出。
- 折叠按钮 `aria-expanded`；抽屉焦点陷阱与 Esc 关闭；关闭后焦点回到触发按钮。
- 状态菜单键盘可达，选择后 `aria-live` 宣告。
- 对比度、焦点样式、reduced motion 见设计系统。
- 快捷键：`/` 搜索、`[` `]` 上/下一节、`f` 专注、`t` 主题、`?` 帮助、`Esc` 关闭浮层。输入框/编辑器内不触发。

## 8. 错误与空状态

| 场景 | 表现 |
|---|---|
| 章节数据加载失败 | 居中说明 + 重试 + 返回目录；不显示半截正文 |
| 章节不存在 | 404 页面 + 目录入口 |
| 元数据缺失 | 右栏显示“本节标注完善中”，不显示虚假 D/P |
| 搜索无结果 | 建议同义词/浏览目录 |
| 本地存储不可用 | 顶部持久提示“当前浏览器禁用了本地存储，学习记录无法保存”，阅读功能仍可用 |
| 导入失败 | 显示具体原因（版本/结构/校验和），保留原数据 |
