## 3. 功能特性验证

1. **中文分词与 2-gram 机制**：
   - 使用标准 `Intl.Segmenter('zh-CN', { granularity: 'word' })` 切词；
   - 补充连续中文字符串 CJK 2-gram 窗口索引，解决方差、夏普等专业复合词在原生分词下偶发被拆切的问题；
   - 单汉字（如“鞅”）自动回退子串索引与扫描机制，保证 100% 召回。
2. **中英文别名双向扩展**：
   - 建立 `content/search/aliases.json`（涵盖 26 组核心术语）；
   - 用户输入 `SVD` 自动关联“奇异值”，输入 `VaR` 自动关联“风险价值”，输入 `Itô` / `ito` 自动关联“伊藤”，输入 `expectation` 自动关联“期望”；
   - 别名纯粹在查询时扩展计算，不污染索引原始文本。
3. **安全高亮与 XSS 防护**：
   - 高亮算法 `getHighlightParts` 基于词边界拆分为原生 React 结构片段，使用 `<mark className="search-highlight">` 渲染；
   - 严禁使用任何 `dangerouslySetInnerHTML` 拼接用户输入；包含 `<script>alert(1)</script>` 等输入时，页面作为纯文本显示，DOM 0 脚本注入。
4. **多维筛选与聚合**：
   - 内容类型：全部 / 知识点 / 定义定理 / 例题 / 习题 / 解析；
   - 章节：全部 34 章下拉筛选；
   - 难度：D1 ~ D5 等级筛选；
   - 优先级：P0 / P1 筛选。
5. **深链定位与快捷键**：
   - 所有检索结果卡片点击直接跳转至 `/learn/{chapterId}#{anchor}`；
   - 全站顶栏搜索按钮（⌘K / Ctrl+K）、首页搜索输入框、阅读页键盘按键 `/` 统一导航至 `/search` 并自动聚焦输入框；
   - 搜索结果支持键盘 `ArrowDown` / `ArrowUp` 切换光标、`Enter` 直达、`Esc` 清空或退出。
6. **搜索历史**：
   - 基于 `localStorage` 记录最近 10 次搜索，支持点击直接回填检索，提供一键“清空历史”。

## 5. DSH 收尾修整

AGY 初版在 30 分钟上限前已交付索引、搜索页与测试，但存在两处影响可读性的问题，由 DSH 在验收中修正：

1. **索引文本重复**：初版正则只匹配到 KaTeX 第一个 `</span>`，把 MathML 与可视 HTML 同时写入正文，片段出现 `X X`、`∑ k ...` 重复。改为匹配 `QMA_MATH_END` 整段，并对 LaTeX 命令做可读化/清理；索引 gzip 从 935KB 降到 849KB，片段可读。
2. **搜索页首屏布局错位**：`.sr-only` 未定义，导致“搜索教材内容”标签在输入框左侧竖排；补全视觉隐藏样式，隐藏浏览器原生 search 清除按钮，搜索页居中（最大 1000px）。
3. 修正索引实体解码顺序，避免 `<` 被标签清理误删；补 `sum/int/inf/lim` 等命令映射。

最终复跑：**9 个测试文件 / 55 项测试通过，build 0 错误**。

## 6. 已知限制与后续建议 (Phase 3 展望)

1. **复杂数学公式结构匹配**：
   - 当前已剥离 LaTeX 命令并提取数学符号（如 `Var`, `Cov`, `E[X]`, `\sigma` 等转换为可读文本）；
   - 对于高度复杂的公式拓扑结构（如多重矩阵方程对偶形式），现主要匹配公式中出现的变量名与英文术语，尚不支持 LaTeX 表达式树的等价结构匹配。
2. **静态索引体积随内容扩展**：
   - 现全书 2,504 个文档压缩后体积为 849KB（小于 1MB 门禁）；
   - 若后续 Phase 3 扩充更多习题题解与衍生知识图谱，可根据篇（8 篇）实施分片索引，实现按篇并行动态载入。
3. **高召回带来宽结果集**：
   - 中文 2-gram 与别名扩展使“期望/协方差/VaR/Black-Scholes”等常见词召回数百条；首条排序正确，但结果页较长。
   - Phase 3 可增加标题精确匹配权重、结果分组折叠与“仅看知识点”默认筛选；当前不删结果，避免漏检。
