## 4. 建议校准规则（下一轮）

1. **逐章重审**，不按关键词；每章先定“本章核心 1–3 节 P0”，其余按下游依赖/考频降级。
2. P0 判据必须满足其一：
   - 量化实习/面试高频直接考；
   - 至少 3 个核心下游章节依赖；
   - 全书后续工具链不可绕过的定义/定理。
3. P1：研究/建模常用，或 2 个以上下游依赖，但可工具辅助。
4. P2：方向选学（衍生品、风险、时序、EVT、非高斯滤波等），理解结论即可。
5. P3：长证明/研究级/细分方向，跳过不影响主线。
6. 目标不是硬配额，而是让 P2/P3 能真实覆盖“可跳过”的节；建议 P0 降到 45–60%，P2+P3 至少 10–15%。
7. 每次调整同步 rationale、reviewedAt；路径 A/C 重新生成后复核覆盖。
