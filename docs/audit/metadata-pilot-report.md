## 4. 10 个难判断节的判定深析

针对在打标过程中存在临界争议的 10 个节，本报告详细记录备选分级、最终裁定与具体教学依据：

### 1. `c01-s3` 集合、函数与确界
- **备选分级**：`D1 / P1` vs `D2 / P1`
- **最终选择**：`D1 / P1`
- **依据**：本节主要建立上界、下界与确界的公理化符号定义，唯一的推导是例 1.6 中对 $f(x)=x/(1+|x|)$ 代入验证 $\sup=1, \inf=-1$。不涉及多步放缩或构造性序列，符合 D1“定义复述、单步计算、直接代入”的典型特征。

### 2. `c01-s4` 实数完备性及其基本推论
- **备选分级**：`D4 / P2` vs `D4 / P3`
- **最终选择**：`D4 / P3`
- **依据**：确界原理、单调有界与区间套定理的相互推导属于纯粹的数学分析内生体系。量化实习笔试/面试极少考察实数完备性等价链条的手撕证明，日常量化建模也完全无需触及实数构造细节。跳过该节证明细节对全书后续主线毫无阻碍，符合 P3“长证明/高级理论、跳过不影响主线”的判定红线。

### 3. `c01-s6` 子列、Cauchy 列与上下极限
- **备选分级**：`D3 / P1` vs `D4 / P2`
- **最终选择**：`D4 / P2`
- **依据**：本节定理 1.15（Bolzano–Weierstrass 定理）采用二分闭区间套法证明，定理 1.17（Cauchy 准则）证明链条跨多页且涉及 $\varepsilon/2$ 构造，上下极限更是分析学思维跨越点，抽象度显著高于普通极限计算，故定为 D4。多数实习考核重在极限计算而非 Cauchy 准则证明，故判定为 P2（建议选学）。

### 4. `c08-s1` QR 分解
- **备选分级**：`D2 / P0` vs `D3 / P0`
- **最终选择**：`D3 / P0`
- **依据**：若仅讲授 Gram–Schmidt 算法，难度可归为 D2；但本节深入剖析了浮点舍入下正交性灾难性损失的数值机制，并完整推导了 Householder 镜面对称反射向量 $v$ 的构造与符号选取算法（定理 8.7 与例 8.2），推导和矩阵变换复杂度达到 D3。

### 5. `c08-s4` 主成分分析
- **备选分级**：`D3 / P0` vs `D3 / P1`
- **最终选择**：`D3 / P1`
- **依据**：对标 `CONTENT_MODEL.md` 第 7.3 节校准示例：“8.4 主成分分析 P1：重要但可由 SVD 工具完成；研究方向偏 P0”。PCA 数学本质由 8.3 SVD 与特征分解完全支撑，且绝大多数实盘实现直接调用 SVD 接口完成，故定为 P1。

### 6. `c08-s6` 量化金融中的应用
- **备选分级**：`D3 / P0` vs `D2 / P0`
- **最终选择**：`D2 / P0`
- **依据**：虽然本节涉及工业级 Barra 结构模型，但核心数学推演主要依靠 Sherman–Morrison–Woodbury（SMW）逆矩阵公式的直接代数展开与主元 Cholesky 截断，推导步骤工整，不需要构造辅助分析对象，符合 D2 特征；因其为组合风险求逆的核心工具，必须掌握，故为 P0。

### 7. `c11-s3` 矩生成函数与特征函数
- **备选分级**：`D3 / P1` vs `D4 / P1`
- **最终选择**：`D3 / P1`
- **依据**：本节引入复分析中的特征函数与 Lévy 逆转公式，虽然具有一定泛函抽象度，但教材正文重点落在性质梳理与初等正态分布 MGF 计算上，未对逆转公式的测度延拓展开冗长证明，难度控制在 D3。

### 8. `c11-s5` 全期望公式与条件分解
- **备选分级**：`D3 / P0` vs `D2 / P0`
- **最终选择**：`D2 / P0`
- **依据**：本节严格限定在离散与具有联合密度的初等条件化框架下，避免了 Radon–Nikodym 导数等一般测度论装置（安排在 C13），双重期望与全方差公式的代数推导直观规整，属于标准 2–3 步可导出的工具，故定为 D2。

### 9. `c33-s1` 无套利与定价基本定理
- **备选分级**：`D3 / P0` vs `D4 / P0`
- **最终选择**：`D4 / P0`
- **依据**：第一基本定理（FTAP）不仅区分了第一类与第二类套利，更关键的是利用凸锥与仿射子空间严格分离超平面定理（Hahn–Banach 定理的几何形式）证明测度严格正性，涉及泛函与拓扑几何分析，属于跨分支高阶理论，故定为 D4。

### 10. `c33-s6` 希腊字母与对冲
- **备选分级**：`D2 / P0` vs `D3 / P0`
- **最终选择**：`D3 / P0`
- **依据**：单算 Delta 或 Vega 仅需一阶偏导（D2），但本节核心内容是推导 Gamma 与 Theta 的控制方程权衡关系（$\Theta + \frac{1}{2}\sigma^2 S^2 \Gamma \approx 0$）以及临近到期平值期权发散的 Pin Risk 动态对冲摩擦，物理直觉与高阶微积分结合深刻，定为 D3。
