## 3. DSH 修正的两处问题

### 3.1 深链被 scrollspy 覆盖

T05 首版在页面加载时，scrollspy 会把 hash 改写成当前顶部节（如 11.1），导致 `#c11-s4` 深链最终滚到错误位置。已修：

- 新增 `deepLinkScrollingRef`，深链滚动期间抑制 scrollspy 的 hash/lastLocation 写入；
- 改为 `window.scrollTo` 显式偏移（170px），并在 900ms 后二次对齐，避免后加载节造成布局位移；
- 验证：hash 保持 `#c11-s4`，h2 在 134px，完整可见。

### 3.2 默认字号与移动端字号

- 桌面默认改为 18px（`lg`），与设计系统一致；
- 640px 以下 `article-content` 使用 `calc(var(--prose-size) - 1px)`，默认 17px，避免移动端 18px 行宽过窄；
- 读者仍可在 Aa 设置中调整 16/17/18/20px。
