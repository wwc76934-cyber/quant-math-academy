# 设计系统与视觉规范

- 版本：v1.0（Phase 0 定稿）
- 气质关键词：**学术、克制、精确、耐读、现代**
- 参考方向：学术出版社的正文排版、现代技术文档的导航、数学教材的公式层级；不复制任何具体站点。
- 关联：`../product/INFORMATION_ARCHITECTURE.md`、`../architecture/TECH_ARCHITECTURE.md`

---

## 1. 设计立场

Quant Math Academy 的视觉不承担“吸引点击”的任务，而承担**降低长时间阅读的认知负担**。页面应像一本排印精良的学术书，而不是一个 SaaS 仪表盘。

三条硬规则：

1. **正文永远是画面主角。** 任何装饰、标签、按钮都不能与正文争夺注意力。
2. **层级靠字体、留白、细线，不靠颜色堆叠。** 全站只有一个强调色；难度与优先级用形状/明度表达，不用红黄绿彩虹。
3. **动效只用于解释状态变化。** 不做入场动画、滚动视差、悬浮卡片、渐变光晕。

## 4. 字体与排版

### 4.1 字体栈

```css
--font-serif: "Source Han Serif SC", "Noto Serif SC", "Songti SC", "STSong", "SimSun", serif;
--font-sans: "Source Han Sans SC", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif;
--font-mono: "JetBrains Mono", "SFMono-Regular", Consolas, "Liberation Mono", monospace;
--font-math: KaTeX_Main, "Times New Roman", serif;
```

- 正文、标题、环境正文：**serif**（中文宋体/思源宋体）。
- 导航、按钮、标签、元信息、表单：**sans**。
- 公式：KaTeX 自带字体，不覆盖。
- Phase 1 使用系统字体栈；Phase 5 再评估是否子集化并打包思源宋体（体积与观感权衡）。

### 4.2 字号与行高

| 角色 | 字号 | 行高 | 字重 | 字体 |
|---|---|---|---|---|
| 正文 | 18px（移动 17px） | 1.9 | 400 | serif |
| 正文小注 | 15px | 1.8 | 400 | serif |
| 章标题 h1 | 40px（移动 30px） | 1.25 | 600 | serif |
| 节标题 h2 | 28px（移动 23px） | 1.35 | 600 | serif |
| 小节 h3 | 21px | 1.45 | 600 | serif |
| 环境标题 | 16px | 1.5 | 600 | serif |
| 环境标签 | 12px | 1.4 | 500 | sans，字距 0.06em |
| UI 正文 | 14px | 1.5 | 400/500 | sans |
| UI 小字 | 12px | 1.45 | 400/500 | sans |
| 数字/公式编号 | 13px | 1.4 | 400 | sans，tabular-nums |

### 4.3 版心与间距

- 正文宽度：默认 `34em`（约 680px，18px 字号）；窄 30em；宽 40em。
- 段落间距：`1.05em`；段首不缩进（网页阅读优先）。
- 标题上间距：h2 `3.2rem`，h3 `2.2rem`；下间距：h2 `1.1rem`，h3 `0.8rem`。
- 列表：左缩进 1.4em，项间距 0.35em。
- 中文不做两端对齐（避免字距撕裂）；使用左对齐，`text-wrap: pretty` 在支持的浏览器启用。
- 英文与数字使用 `font-variant-numeric: tabular-nums` 仅在表格/编号中；正文不强制。
- 标点：中文全角；英文术语前后留半角空格（正文内容已处理，UI 文案遵循）。
- 连字符：不自动断词；长公式/长单词允许容器滚动。

### 4.4 数学排版

- 行内公式：`font-size: 1.04em; vertical-align: -0.05em;` 不改变行高。
- 独立公式：上下 margin `1.1em`，容器 `overflow-x: auto`，滚动条细。
- 公式编号：右对齐到版心外侧，`13px`，`--ink-muted`，`(11.2)`。
- 公式与正文之间不额外加空行（源文已控制）。
- 矩阵、分段函数、多行对齐保持 KaTeX 默认间距；不为“好看”改字号。
- 公式容器背景不加色；仅悬停时显示复制按钮。
- 打印：公式不缩放，超宽时缩至页面宽度（`max-width:100%`）。

## 5. 布局

### 5.1 全局

- 最大内容宽度：`1440px`；两侧最小留白 24px。
- 顶栏：高 `56px`，sticky，`background: var(--bg)`，底部 `1px solid var(--line)`。
- 阅读页子导航：高 `44px`，sticky 在顶栏下方（`top:56px`）。
- 主内容区：`padding-top: 32px`；移动端 20px。

### 5.2 阅读页三栏

```css
.reader-grid {
  display: grid;
  grid-template-columns: 264px minmax(0, 1fr) 272px;
  gap: 48px;
  max-width: 1440px;
  margin: 0 auto;
  padding: 0 32px;
}
.reader-article { max-width: 720px; margin: 0 auto; }
```

- ≥1600px：两侧留白增大，正文不超过 760px。
- 1280–1599px：三栏，gap 40px。
- 1024–1279px：左栏 240px + 正文；右栏折叠为浮动按钮/抽屉。
- <1024px：单栏；左右栏为抽屉。
- 侧栏 sticky：`top: 112px; max-height: calc(100vh - 128px); overflow:auto;` 细滚动条。
- 侧栏不投阴影；用 1px 分隔线与主内容分开（可选，优先留白）。

### 5.3 间距尺度

`--space-1: 4px; --space-2: 8px; --space-3: 12px; --space-4: 16px; --space-5: 24px; --space-6: 32px; --space-7: 48px; --space-8: 64px; --space-9: 96px;`

- 组件内部：8/12/16。
- 区块之间：32/48/64。
- 不随意使用 20/28 等非尺度值。

### 5.4 圆角与阴影

- 圆角：`--radius-sm: 2px; --radius-md: 4px; --radius-lg: 6px;` 卡片 4px，按钮 4px，输入框 4px。
- 阴影：默认无。仅弹层/下拉使用 `0 8px 24px rgba(20,18,14,.08), 0 1px 2px rgba(20,18,14,.06)`。
- 不使用 12px 以上大圆角、玻璃模糊、彩色阴影。

## 6. 组件规范

### 6.1 按钮

| 类型 | 外观 | 用途 |
|---|---|---|
| Primary | 墨色底 `--ink`、纸色字；悬停 `--accent` | 页面主操作（继续阅读、开始） |
| Secondary | 透明底、1px line 边框、墨色字 | 次要操作（标记状态、展开） |
| Ghost | 无边框、次要色字；悬停浅底 | 工具栏、图标按钮 |
| Danger | 透明底、`--accent` 字/边框 | 清空数据（需二次确认） |

- 高度：32px（小）、36px（中）、44px（移动主操作）。
- 内边距：12–16px；图标按钮 32×32。
- 不使用渐变、发光、悬浮上移。
- 焦点：2px `--focus` outline，offset 2px。
- 禁用：`opacity:.45; cursor:not-allowed`，不使用灰色块掩盖文字。

### 6.2 徽标（D/P）

- 形状：小矩形/胶囊，高 20px，sans 11px，字距 0.04em。
- 难度：`D1`–`D5` + 5 个小圆点（直径 4px，间距 3px）。已达成等级用 `--ink`，未达成用 `--line`。不使用颜色。
- 必要性：
  - `P0`：`--accent` 实心底 + 纸色字。
  - `P1`：透明底 + `--accent` 1px 边框 + 强调色字。
  - `P2`：透明底 + `--line-strong` 边框 + 次要色字。
  - `P3`：透明底 + `--line` 边框 + 弱化色字。
- 悬停显示 tooltip：名称 + 一句话定义 + “为什么”链接到 rationale。
- 未标注：显示 `待标注`（虚线框），不显示猜测值。

### 6.3 侧栏目录

- 宽度 264px；字体 sans 13px；行高 1.6。
- 篇标题：11px，大写，字距 0.08em，`--ink-muted`；可折叠。
- 章行：14px，字重 500；当前章 `--ink`，其余 `--ink-secondary`。
- 节行：13px，左缩进 12px；当前节：左侧 2px `--accent` 竖线 + `--accent-soft` 底；不改变字重。
- 状态点：6px 圆点，未开始空心，学习中半填充，已学习实心 `--ink-secondary`，已掌握实心 `--success`，需复习 `--warning`。不使用勾选动画。
- 目录滚动条：6px，透明轨道，`--line-strong` 滑块，悬停可见。

### 6.4 页内目录

- 仅列 `h2`/`h3`；h3 缩进 10px。
- 当前项左侧 2px 强调线；不加背景。
- 顶部标题“本页目录”11px 大写字距。
- 点击平滑滚动；滚动时更新 `aria-current="true"`。

### 6.5 环境块

所有环境共享：

```
┌ 标签行：定义 11.1 ·（期望）                  [复制链接]
│
│ 正文……
└
```

- 上间距 32px，下间距 32px；环境内部段落间距 0.9em。
- 标签行：sans 12px，`--ink-muted`，字距 0.06em；编号用 `--ink` 500；名称用 `--ink-secondary`。
- 复制链接按钮：默认透明，悬停显现；图标 14px。

差异化：

| 环境 | 容器 | 标签 | 说明 |
|---|---|---|---|
| 定义 | 左侧 2px `--line-strong`，padding-left 20px | “定义” | 最克制，像词典条目 |
| 定理 | `--bg-subtle` 底，1px `--line` 边，padding 20px 24px，左侧 3px `--ink` | “定理” | 视觉重量略高，但不做成彩色卡片 |
| 引理/命题/推论 | 同定理，左侧线改为 `--line-strong` | 对应名称 | 与定理同族 |
| 证明 | 无底色；左侧 1px 虚线 `--line-strong`；文字 `--ink-secondary`；结束符右对齐 | “证明” + 折叠按钮 | 默认展开；可折叠为一行 |
| 例题 | 上方 1px `--line`，padding-top 16px | “例” + 编号，强调色 | 便于扫描 |
| 解 | 无边框；标签“解” `--ink-muted`；正文同正文 | “解” | 与例题成组，不重复卡片 |
| 注记 | 左侧 1px 虚线，padding-left 16px；字号 16px | “注记” | 弱于正文，不抢注意力 |

- 定理/定义不添加图标；不使用灯泡、感叹号等 emoji。
- 证明折叠：按钮文字“收起证明 / 展开证明”，`aria-expanded`；折叠时显示首行摘要（前 60 字），不显示空白。

### 6.6 公式

- 容器：`display:grid; grid-template-columns: minmax(0,1fr) auto; align-items:center;`
- 公式体居中或左对齐？**居中**（数学教材惯例），编号右对齐；超宽时公式体左对齐并可滚动。
- 悬停显示右上角“复制 LaTeX”图标按钮；点击后 toast“已复制 LaTeX”。
- 编号可点击复制该公式链接（`#c11-eq-11.2`）。
- 不添加公式背景、边框、阴影。

### 6.7 习题卡

- 容器：`border-top:1px solid var(--line)`；无圆角卡片堆叠。
- 题号：sans 13px，`--ink-muted`，`tabular-nums`；题干 serif 17px。
- 操作行：右侧 ghost 按钮“展开解析 / 收起解析”“标记做对”“加入错题”。
- 解析展开：左侧 2px `--line`，背景 `--bg-subtle`，padding 16px 20px；顶部“解析”标签；不盖住题干。
- 状态：已做对左侧 2px `--success`；做错左侧 2px `--warning`；收藏显示书签图标（不用黄色星星）。
- 移动端：操作行换行，按钮高度 36px，避免误触。

### 6.8 卡片

- 仅用于首页“继续学习”、路径卡、统计数据块。
- `background: var(--bg-elevated); border:1px solid var(--line); border-radius:4px; padding:24px;` 无阴影。
- 悬停：边框变 `--line-strong`，不位移、不放大。
- 不在卡片里再套卡片；用分隔线分组。

### 6.9 进度

- 线性进度条：高 4px，轨道 `--bg-inset`，填充 `--ink`（完成）或 `--accent`（当前路径）；圆角 2px。
- 百分比文字：sans 12px，`tabular-nums`，右对齐。
- 环形进度：仅首页“继续学习”使用 1 个，线宽 3px，直径 44px；不滥用。
- 热力图：10px 方格，2px 间距，5 档明度（同一色相），无圆角；图例“少 → 多”。

### 6.10 表单与搜索

- 输入框：高 40px，1px `--line` 边框，4px 圆角，背景 `--bg`；聚焦 2px `--focus` 外环。
- 搜索框：高 44px，左侧放大镜图标；占位文字“搜索知识点、定理、习题…”。
- 筛选 chip：高 28px，1px 边框，4px 圆角；选中为墨色底纸色字；不使用彩色。
- 下拉/弹层：白底，1px 边框，阴影（仅此处），4px 圆角；最大高 320px，内部滚动。

### 6.11 提示与反馈

- Toast：底部居中或右下，深色底纸色字，4px 圆角，3 秒自动消失；不遮挡正文操作。
- Tooltip：深色底，12px，最大宽 240px；延迟 300ms。
- 空状态：一句说明 + 一个明确行动；不使用插画。
- 错误：文字说明 + 重试；不使用红色大横幅（除非阻断）。

## 8. 图标

- 使用内联 SVG，线宽 1.5px，尺寸 16/18/20；颜色 `currentColor`。
- 常用：搜索、菜单、关闭、太阳/月亮、字号、宽度、专注、上一/下一、复制、链接、书签、笔记、检查、时钟、箭头。
- 不使用 emoji 作为图标；不使用彩色图标。
- 图标按钮必须有 `aria-label` 与 tooltip。

---

## 9. 动效

- 时长：120–180ms；缓动 `cubic-bezier(.2,.7,.3,1)`。
- 允许：悬停颜色/边框变化、抽屉滑入、折叠展开、toast 淡入、状态点变化。
- 禁止：页面入场动画、滚动触发的逐段浮现、卡片悬浮上移、无限循环动画、粒子/彩带。
- `prefers-reduced-motion: reduce` 时，所有 transition/animation 设为 0.01ms，抽屉直接显示。
- 折叠使用 `grid-template-rows` 或高度过渡，避免布局跳动；不做高度 0→auto 的 jank。

---

## 10. 深色模式

- 通过 `<html data-theme="dark">` 切换；CSS 变量覆盖。
- 首屏内联脚本读取 `localStorage`/`prefers-color-scheme`，避免白闪。
- 深色下公式、表格、代码块保持足够对比；不使用纯黑底。
- 图片（未来）在深色下不反色；必要时加 1px 边框。
- 主题切换不重载页面；切换按钮图标从太阳变月亮（无旋转动画）。

---

## 11. 响应式

| 断点 | 行为 |
|---|---|
| < 640 | 单栏；正文 17px；左右 padding 20px；顶栏 52px；底部操作栏 |
| 640–1023 | 单栏 + 目录抽屉；正文 18px；右栏信息 sheet |
| 1024–1279 | 左目录 240px + 正文；右栏按钮打开抽屉 |
| 1280–1599 | 三栏 264 / 720 / 272 |
| ≥1600 | 三栏，正文 ≤760，留白增大 |

- 触摸目标 ≥44×44px（移动端主操作）。
- 不隐藏关键功能：移动端必须能切换主题、标记状态、上一节/下一节。
- 表格：外层 `overflow-x:auto`；不强制换行破坏表格结构。
- 长公式：容器滚动，页面不横向滚动。

---

## 12. 可访问性

- 正文对比度 ≥ 7:1；元信息 ≥ 4.5:1。
- 焦点环 2px，offset 2px，颜色对比 ≥ 3:1。
- 标题层级不跳级（h1→h2→h3）。
- 图标按钮有文字替代；装饰性 SVG `aria-hidden="true"`。
- 折叠按钮 `aria-expanded`；抽屉焦点陷阱；Esc 关闭。
- 公式：KaTeX MathML 输出；行内公式朗读不打断句子。
- 表格有 `<caption>`（如源文有标题）或 `aria-label`。
- 键盘全部可达；不依赖 hover 才能完成操作。
- 色盲：D/P 不仅靠颜色，使用字母+形状；状态点配合文字 tooltip。
- 动效尊重 reduced motion。
- 打印：隐藏导航/按钮，正文黑色，公式不裁切，章节从新页开始。

---

## 13. 文案语气

- 简洁、克制、专业；不卖萌、不喊口号、不使用“恭喜你”“你只需要记住”。
- 按钮用动词：“继续阅读”“标记为已学习”“展开解析”“导出数据”。
- 空状态给下一步：“还没有学习记录。从第一章开始。”
- 错误说清原因与动作：“章节数据加载失败。请重试，或返回目录。”
- 标注解释用事实：“P0：量化实习笔试高频；后续 5 节依赖本节。”不写“非常重要”。

---

## 14. 禁止项（视觉验收会逐条检查）

1. 紫色/蓝色渐变背景、发光按钮、玻璃拟态。
2. 大圆角（>8px）卡片堆叠、彩色阴影、悬浮上移。
3. emoji 当图标；彩色难度标签；红黄绿状态滥用。
4. 正文全宽超过 42em；长段落居中。
5. 首页没有“继续学习”而只有宣传文案。
6. 阅读页出现推荐流、广告位、弹窗、悬浮客服。
7. 动画干扰阅读；滚动视差；自动轮播。
8. 深色模式纯黑底 + 纯白字。
9. 侧栏与正文同等视觉重量；导航比正文更抢眼。
10. 使用未授权字体/图片；打包大体积字体而不做子集化。

10. 截图与设计稿对照，字体、间距、颜色 token 一致。
