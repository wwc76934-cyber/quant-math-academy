## 关键决策

1. 纯静态站点，无后端；学习数据本地保存，支持导出/导入。
2. Vite + React + TypeScript；构建期 KaTeX 预渲染，客户端不跑 KaTeX。
3. 知识点粒度 = 一级节；环境作为锚点。
4. 难度（D1–D5）与必要性（P0–P3）分离，人工策展，保留理由。
5. 路径只改推荐顺序，不删减教材内容。
6. 代码与内容许可分离；未经作者确认不公开发布。
