# 开源范围与许可选项（供用户决策，不构成法律意见）

- 日期：2026-11-10
- 前提：代码与教材内容可分离；内容版权仍待用户确认。
- 当前不创建公开仓库、不发布站点、不预选许可证。

## 选项 A：代码 MIT + 内容 CC BY-NC-SA 4.0 + 公开仓库

| 项 | 说明 |
|---|---|
| 代码 | MIT：允许商用、修改、再分发，保留版权声明 |
| 内容 | CC BY-NC-SA 4.0：署名、非商业、相同方式共享 |
| 公开范围 | 代码 + `src/` 正文 + 构建产物 |
| 适合 | 希望公开传播、但不希望他人直接商业售卖内容 |
| 风险 | “非商业”定义复杂；不是 OSI 意义上的开源内容；部署站点可能被视为商业使用（广告/付费） |
| 前置 | 你确认内容原创/已授权；法律复核 |

## 选项 B：代码 Apache-2.0 + 内容保留所有权利 + 公开代码、不公开内容

| 项 | 说明 |
|---|---|
| 代码 | Apache-2.0：专利授权、商用友好、需 NOTICE |
| 内容 | All rights reserved；`src/` 不进入公开仓库或仅私有子模块 |
| 公开范围 | 构建工具、前端、内容模型；正文不公开 |
| 适合 | 代码开源、内容仍需保护/未来商业化 |
| 风险 | 公开仓库无法直接构建完整站点；需要“示例内容”或私有内容包 |
| 前置 | 拆分公开/私有内容流程；README 说明如何接入自有内容 |

## 选项 C：代码 MIT + 内容 CC BY 4.0 + 完全公开

| 项 | 说明 |
|---|---|
| 代码 | MIT |
| 内容 | CC BY 4.0：允许商用/修改，只需署名 |
| 公开范围 | 全部 |
| 适合 | 希望最大化传播、不介意商业再利用 |
| 风险 | 他人可直接售卖内容；需确认你拥有完整权利 |
| 前置 | 内容原创/授权确认；法律复核 |

## 选项 D：暂不开源，私有仓库 + 私有部署

| 项 | 说明 |
|---|---|
| 代码/内容 | 均保留所有权利 |
| 公开范围 | 无 |
| 适合 | 继续打磨、商业化或版权未定 |
| 风险 | 无开源传播；仍需备份/部署安全 |
| 前置 | 无 |

## 决策所需回答

1. 教材内容是否为你原创，或已获得公开/再分发授权？
2. 是否允许他人商用？是否要求署名/相同方式共享？
3. 公开仓库是否必须包含 `src/` 正文？
4. 是否部署公开站点？若部署，是否含完整正文？
5. 代码许可偏好：MIT（简单）或 Apache-2.0（专利条款）？

## 我的建议（非法律意见）

- 若内容版权清晰且希望传播：**选项 A** 最接近“开放但保护内容”的意图，但需接受它不是 OSI 开源内容许可。
- 若内容版权未定：**选项 D** 或 **选项 B（只开代码）**，先不要公开正文。
- 无论选哪个，发布前都需要 `LICENSE`、`THIRD_PARTY_NOTICES`、内容版权声明与一次人工复核。
