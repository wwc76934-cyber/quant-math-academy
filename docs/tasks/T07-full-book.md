   - 不再显示“内容接入中”；

   - 试点章与未标注章在视觉上只通过 D/P 有无区分，不通过禁用。

   - “继续学习”和“今日下一节”可以落在任意章；
   - 保持阅读位置优先；

4. 失败态：
   - 章节 manifest/节 HTML 加载失败时显示错误与重试，不用“内容接入中”掩盖真实 404。
5. 测试：
