# T09 — 先修/相关知识关系图与跨章跳转

## 1. 前置

- T07 已开放全书 34 章；T08 搜索已完成。
- 目前只有 C01/C08/C11/C33 共 25 节有 reviewed D/P/先修/相关元数据；其余 30 章为“标注完善中”。
- 阅读页右栏已显示单节的先修/相关链接（直接读 metadata），但没有全局图、没有传递先修链、没有反向引用。

## 2. 目标

把零散的先修/相关字段变成可校验、可浏览、可跳转的关系图；不伪造未标注章的边，不引入图数据库/外部服务。

## 3. 构建期图数据

新增 `tools/content/build-graph.mjs`：

- 输入：`content/metadata/chapters/*.json` + `content/generated/site/book.json`。
- 输出：`content/generated/site/graph.json`。
- 节点：全部 219 节：
  ```json
  {"id":"c11-s4","chapterId":"c11","number":"11.4","title":"概率不等式",
   "chapterTitle":"期望、方差、矩与概率不等式","difficulty":"D3","priority":"P0",
   "annotated":true}
  ```
- 边：
  - `prerequisiteEdges`: `{from, to, strength}`，`from` 是先修，`to` 是本节。
  - `relatedEdges`: `{a, b}` 无向，去重。
- 反向索引：`incoming`（哪些节把本节列为先修/相关），构建期生成。
- 传递先修链：构建期计算 `ancestors`（最多 3 层，去重，防环）。
- 校验：
  - 所有 from/to/a/b 必须存在于 219 节；
  - 不得自指；
  - prerequisite 子图必须是 DAG（发现环则 error，列出环）；
  - related 去重；
  - 未标注节的边为空，不推断；
  - 每章覆盖统计。
- 输出 `graph-manifest.json`：节点数、标注节点数、边数、最大先修深度、warnings。
- 测试：节点 219、25 标注、无环、未知 ID 报错、自指报错、反向索引一致。

## 4. Web

- 新增 `/graph` 知识关系页：
  - 标题“知识关系”；说明“先修是必要条件，相关是横向关联；未标注章不生成边”。
  - 顶部统计：219 节 / 25 节已标注 / 先修边 / 相关边 / 0 环。
  - 按章分组；每节一行：编号、标题、D/P、先修 chips、相关 chips、被引用数。
  - 点击 chip 跳到 `/graph?section=...` 或 `/learn/...`；支持 `?section=` 高亮。
  - 未标注章显示“标注完善中”，不显示假边。
  - 过滤：只看已标注 / 全部；按篇/章；按 P0/P1。
  - 空/错误/加载态。
- 阅读页右栏增强：
  - “先修链”：2–3 层传递先修，显示编号+标题；点击跳转。
  - “被引用”：哪些节把本节列为先修/相关；无则“暂无”。
  - “查看完整关系” → `/graph?section={current}`。
  - 未标注节不显示假链。
- 入口：
  - 阅读页右栏“查看完整关系”；
  - 目录页 header 增加“知识关系”文字链接（不新增大导航项）；
  - `/graph` 可直接访问。
- 不新增图形库；用学术列表/关系行，不画低质 SVG 网络图。

## 5. 测试
