# T11 — 学习路径 A/B/C/D（Phase 3 第一步）

## 1. 背景与决策

- Phase 2 已实现：34 章全部可读、全文搜索、知识关系图；D/P 标注已完成 19 章 / 113 节，剩余 15 章为“标注完善中”。
- 学习路径不应继续等待全部标注；先用现有 19 章 reviewed 数据 + 全书 219 节目录构建路径 MVP，未标注章不伪造 D/P。
- **路径只改变推荐顺序与节奏，不限制/不删除任何教材内容**。任何章、任何节始终可从目录/阅读页访问。

## 2. 目标

实现 4 条路径的浏览、选择、进度与下一步推荐：

- **A 量化实习冲刺**：8 周，优先 P0/P1 与面试高频；覆盖最小可面试集合。
- **B 系统数学进阶**：20 周，按教材 8 篇顺序完整走一遍。
- **C 量化研究应用**：14 周，偏概率/统计/随机过程/时间序列/优化，连接 C31–C34 研究应用。
- **D 自由学习**：无固定节奏，保留当前阅读顺序；路径页显示“自由模式”。

## 3. 路径数据

新增 `content/paths/paths.json`：

```json
{
  "schemaVersion": 1,
  "paths": [
    {
      "id": "internship",
      "code": "A",
      "title": "量化实习冲刺",
      "weeks": 8,
      "audience": "准备 2027 量化实习面试",
      "description": "……",
      "principles": ["只决定推荐顺序，不限制阅读", "先 P0 后 P1", "每周留复习窗口"],
      "weeksPlan": [
        {
          "week": 1,
          "theme": "概率与线性代数地基",
          "sectionIds": ["c09-s2", "c04-s2"],
          "outcome": "……",
          "estimatedMinutes": 180
        }
      ],
      "checkpoints": [{"afterWeek": 4, "title": "……", "sectionIds": []}]
    }
  ]
}
```

- sectionIds 必须全部存在于 `book.json`；每周 4–10 节，总量不超过 219。
- A 路径可重复/跳过标注不完整的章，但必须诚实标注“标注完善中”，不得伪造 D/P。
- B 路径按 part/chapter 顺序覆盖 219 节；C 路径偏后半；D 无 weeksPlan。
- 每个路径给出总预计时长、周数、覆盖章节/节数。
- 构建期校验：ID 存在、无重复、周计划不引用未定义节、路径不包含“删除内容”语义；输出 `content/generated/site/paths.json` 或直接读 `content/paths`。

## 4. Web

- `/paths`：4 条路径总览；每张路径卡（学术列表式，不做花哨渐变）显示 A/B/C/D、标题、周数、预计时长、覆盖章/节、已选状态、开始/继续按钮。
- `/paths/:mode`：
  - 路径说明、原则、周计划时间线；
  - 本周推荐、下一节推荐（按 sectionIds 顺序，跳过已完成 done/master）；
  - 完成百分比（按路径 sectionIds 与 store.progress 计算）；
  - 每周可展开节列表，点击进入 `/learn/{chapterId}#{sectionId}`；
  - 未标注章显示“标注完善中”，不显示假 D/P；
  - “切换路径”不丢失阅读进度；“路径只影响推荐”说明常驻。
- 首页“学习路径”区块：从占位改为 4 条路径入口；当前路径高亮；“今日下一节”优先当前路径，其次 lastLocation。
- 顶栏“学习路径”指向 `/paths`；现有 `pathsPath` 已存在。
- 路径选择写入 store `path.active`；扩展 `path.startedAt`/`path.mode` 时保持向后兼容（localStorage 旧数据）。
- 进度页 `/progress` 可继续占位，但首页/路径页必须真实使用 store.progress。

## 5. 测试

- 路径数据：4 条、ID 唯一、sectionIds 全部存在、周计划不重复、B 覆盖 219、A/C 不引用不存在节。
- 路径页：4 卡渲染、选择 A 后首页高亮、本周推荐、完成一个节后进度变化、切换路径不丢进度。
- 未标注章显示“标注完善中”；不出现假 D/P。
- 路径不影响阅读页可访问性（任意章仍可读）。
- 既有 69 项 Web 测试 + 52 项内容测试继续通过；build 0。
