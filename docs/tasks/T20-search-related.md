# T20 — 搜索结果相关知识点 chips（Phase 4 小切片）

## 1. 背景

- 搜索页已有结果类型/章/难度/优先级筛选与深链。
- `graph.json` 已有 446 条相关边、0 环；但搜索结果没有利用横向关系。
- T14 公式收藏多次超时，先做一个低风险、可独立验收的 Phase 4 小功能。

## 2. 目标

在搜索结果卡片下增加最多 **2 个“相关：节号 标题” chips**：

- 数据来自 `graph.json` 的无向相关边（`relatedEdges`）；
- 只展示真实存在的节；不伪造、不猜；
- 点击跳 `/learn/{chapterId}#{sectionId}`；
- graph 加载失败/无相关时静默隐藏，不影响搜索结果；
- 不新增依赖，不改内容管线。

## 3. 实现要点

- 懒加载 graph：首次需要时 `loadGraph()`；已有缓存/错误处理可复用。
- 为每个搜索结果找相关边：
  - `relatedEdges` 可能是 `{a,b}` 或 `{source,target}`，以实际类型为准；
  - 排除自身；
  - 用 book/section 索引解析 `chapterId`、节号、标题；
  - 最多 2 条，去重。
- 渲染在结果卡片底部，小号学术标签，不用彩色渐变。
- 可访问性：`<Link>` 有明确文本，键盘可达。
- 移动端换行不溢出。

## 4. 测试

- 有相关边：结果卡片出现 chips，文本/链接正确；
- 无相关边/空图：不渲染 chips，结果仍显示；
- graph 请求失败：静默降级，搜索不失败；
- 既有 110 Web + 58 内容测试不回归；build 0。

## 5. 约束

- 只改 `web/`；不改 `src/`、metadata、paths、发布配置。
- 不新增依赖；不做后端。
- 只做 chips，不做“学习建议/公式收藏”。

## 6. 验收

1. 搜索结果出现最多 2 个真实相关节 chips。
2. 点击进入正确阅读页深链。
3. graph 失败不影响搜索。
4. build/test；截图搜索页。
