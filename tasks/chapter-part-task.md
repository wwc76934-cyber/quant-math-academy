# 章节分段写作协议（自包含，无需再读其他规范文件）

你为《量化数学进阶教材》撰写某章的**一个片段**。调用你的提示词给出：章号、章名、片段（前段/后段）、输出文件、节次清单、编号预算。

## 一、增量落盘规程（最重要，违反会导致任务失败）

单次输出过长会耗尽你的空间。必须**分段写入**：

1. 第一次 `write`：只写**导言 + 第一节的开头部分**，控制在 **3,000 字符以内**。
2. 之后每次用 pwsh 追加一段，**每次不超过 3,000 字符**（这一粒度经实测才能避免耗尽空间；写大段必然失败）：
   ```
   $p='C:\...\文件.md'
   $text = @'
   （这一段内容）
   '@
   [System.IO.File]::AppendAllText($p, $text, [System.Text.UTF8Encoding]::new($false))
   ```
   注意 here-string 结束符 `'@` 必须位于行首。段与段之间自行补换行。**当前 Windows PowerShell 5.1 不支持 `-Encoding utf8NoBOM`，不要使用该参数**；上面的 .NET 写法可保证 UTF-8 无 BOM 且不自动添加换行。读取中文文件统一用 `Get-Content -Encoding UTF8`。
3. 重复追加直到全部内容写完。**不要**试图一次写完，**不要**反复重写整个文件（重写会再次消耗等量空间）。
4. 全部写完后只做最小自检：编号连续性、`$$` 成对、`□` 与 `**证明**` 配平。
5. **绝不**把正文粘贴到对话里，**绝不**在对话中起草或复述内容。报告只需几行。
6. 不要读任何已有章节文件；不要 grep 全书。
7. **读取计划文件时必须局部读取**：`tasks/chapter-plans.md` 含十余章计划，整读会吃掉你大量空间并导致任务失败。正确做法是先 `grep` 定位你的条目号（例如 `C29-A`）得到行号，再用带 `offset`/`limit` 的 `read` 只取该条目附近约 40 行。**绝不整读该文件**。

## 二、铁律：不得压缩

用户明确要求「不能因为需要一次性完成整本书，就压缩后续章节的数学内容」。

- 宁可多分几次追加，也不要删掉定义、定理、证明、例题或推导步骤。
- 严禁「略」「显然」「同理可证」「读者自证」「留给读者」。
- 证明必须完整展开；不得把完整证明降级为「证明思路」，除非确需更深层结果，且须明确标注哪些部分留给何处。
- 整章片段的目标体量：**总字符 16,000–24,000**。
- **超长无需请示**：若为保全全部定义、定理、证明、例题与推导步骤而超出 24,000，直接保留全部内容并在回报中注明实际字符数即可。已有片段写到 38,000–53,000 字符并被采纳。**严禁**为了凑进区间而删减任何数学内容，也**不要**就此向我提问（裁决已定：宁长勿删）。

## 三、片段拼接规则

- **前段**：首行严格为 `# 第N章　章名`（章号与章名之间是全角空格 `　`），随后是**无小标题**的章首导言，再写你负责的各节。**不要**写 `## 本章小结` 与 `## 习题`。
- **后段**：**不要**写 `# 第N章` 标题，直接从你负责的第一个 `## N.x` 节开始；必须包含 `## 本章小结`（连贯散文）与 `## 习题`。
- 后段可引用前段结果：「由定理 N.k」「由式（N.j）可知」。

## 四、编号规则（硬性）

- 定义、定理、引理、命题、推论**共用一套章内序号**，按出现顺序连续递增，不跳号不重复。
- 例题用**独立**计数器：`**例 N.1**`、`**例 N.2**` …
- 独立公式用 `$$ ... \tag{N.j} $$`，`j` 章内连续递增。
- 严格停留在提示词分配的区间内，**不得进入另一片段的区间**。
- 若需要更多环境，用不占序号的「注记」。

## 五、格式细则

- `**定义 N.1（名称）**`、`**定理 N.2（名称）**` 各占一行，其后空一行再写内容。
- 证明：单独一行 `**证明**` 起，单独一行 `□` 止（该行只有这一个字符），前后各空一行。
- 例题：`**例 N.1**` → 空行 → 题目 → 空行 → `**解**` → 完整推导。
- 节标题 `## N.1 名称`，子节 `### N.1.1 名称`。
- 正文以连贯学术散文为主，**不使用项目符号清单式写作**；确有并列条目时才用有序列表。
- 行内公式 `$...$`，独立公式 `$$...$$`。
- 期望 `\mathbb E`、方差 `\operatorname{Var}`、协方差 `\operatorname{Cov}`、概率 `\mathbb P`、σ-代数 `\mathcal F`/`\mathcal G`。
- 向量矩阵用粗体 `\boldsymbol`，转置统一 `^\top`。
- **LaTeX 控制词后若紧跟字母必须加空格**：写 `\to A`、`\le x`，不可写 `\toA`、`\lex`。
- 「几乎必然」写全称，不缩写为 a.s.
- 交叉引用用中文书名号式：「由式（11.2）可知」「定理 11.3 给出」。
- `## 习题` 中题目编号 `1. `、`2. ` …（数字、句点、空格），题数按提示词（通常 20–22 题），按知识顺序与难度递进，覆盖概念辨析、计算、证明与综合应用。
- **不要**在章节文件里写习题解析（解析另有文件）。
- 禁止 TODO、占位内容、对话式表达（「接下来我们来看看」「你只需要记住」「恭喜你」）、表情符号、Obsidian 语法（wikilink、callout）。

## 六、完成后报告（从简）

只回报：输出路径、总字符数、你使用的环境编号区间、例题区间、公式 tag 区间；后段另报习题数。不要贴正文。


## 红线补充（务必遵守，违反会被退回重写）

1. **证毕符**：证明结束必须写**独占一行**的字面 `□`（前面留一个空行）。**禁止**写成 `$\square$`、`\square`、`\blacksquare`，也禁止接在句子末尾（如「……成立。□」）。
2. **术语**：一律写全称「几乎必然」。**禁止** `a.s.`、`a.e.`、「几乎处处」等缩写或变体。同理写「几乎 surely」的混用也不允许。
3. **数学环境内不得出现中文字符**（包括 `\text{...}` 内）。需要中文限定语时，把它写在公式**外面**的散文里。例如不要写 `X=Y\quad\text{a.s.}`，而应写公式 `$$X=Y$$` 后接一行「几乎必然成立。」
4. **控制词后接字母必须留空格**：`\to A`（不是 `\toA`）、`\le 0`、`\mathbb E`。
5. 转置写 `^\top`；期望 `\mathbb E`；概率 `\mathbb P`；方差 `\operatorname{Var}`；协方差 `\operatorname{Cov}`；σ-代数 `\mathcal F`／`\mathcal G`；向量与矩阵用 `\boldsymbol`。
