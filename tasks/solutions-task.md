# 习题解析写作协议（自包含，无需再读其他规范文件）

你为《量化数学进阶教材》某一章撰写**习题参考答案与解析**。调用你的提示词给出：章号 `N`、章节文件路径、解析输出文件路径。

## 一、增量落盘规程（最重要，违反会导致任务失败）

单次输出过长会耗尽你的空间。必须**分段写入**：

1. 先用 `grep`（pattern `^## `）在章节文件中定位 `## 习题` 的行号，再用 `read` 从该行读到文件末尾，取得题目原文。**严禁**读取章节正文其他部分。
2. 第一次 `write`：写首行标题 + 前 3–4 题的解析，控制在 **3,000 字符以内**。
3. 之后每次用 pwsh 追加若干题，**每次不超过 3,000 字符**：
   ```
   $p='C:\...\Cxx-solutions.md'
   $text = @'
   （这一段内容）
   '@
   [System.IO.File]::AppendAllText($p, $text, [System.Text.UTF8Encoding]::new($false))
   ```
   here-string 结束符 `'@` 必须位于行首。**当前 Windows PowerShell 5.1 不支持 `-Encoding utf8NoBOM`，不要使用该参数**；上面的 .NET 写法可保证 UTF-8 无 BOM。读取中文文件统一用 `Get-Content -Encoding UTF8`。
4. 重复追加直到全部题目写完。**不要**反复重写整个文件（重写会再次消耗等量空间）。
5. 写完只做最小自检：题号 1..M 连续且与该章习题数相等、`$$` 成对、`□` 与 `**证明**` 配平。
6. **绝不**把解析正文粘贴到对话里，**绝不**在对话中起草。报告只需几行。
7. 不要修改章节文件本身。

## 二、铁律：不得压缩

- 解析必须完整，不得为省长度而跳步或删减推导。
- 严禁「略」「显然」「同前」「读者自证」「留给读者」。
- 综合题要给出完整推导过程与最终结果。

## 三、输出格式（自动校验脚本逐条检查，必须精确）

- 第 1 行严格为：`# 第N章习题参考答案与解析`（N 用阿拉伯数字，无空格）
- 每题一个小标题，严格形如 `## 1. `、`## 2. `（数字、句点、一个空格）位于行首
- 编号 1..M 连续无跳号，M 必须与该章 `## 习题` 的题目数**完全相同**
- 小标题下为正式学术中文散文，不使用项目符号清单式写作

## 四、质量要求

- 基础题给出关键步骤；综合题给出完整推导。
- 证明类解答以单独一行 `**证明**` 起、单独一行 `□` 止。
- 解释关键依据，并指出该题常见的错误做法（本书解析的特色，务必包含）。
- 必要时给出推广或替代解法。
- 若题目引用了你未读到的「例 N.k」「定理 N.k」，依据题面自身条件求解，不要为此去读正文。

## 五、数学排版

- 行内公式 `$...$`，独立公式 `$$...$$`。
- 解析中的独立公式**一律不要**使用 `\tag{...}`（避免与正文编号冲突）。
- 期望 `\mathbb E`、方差 `\operatorname{Var}`、协方差 `\operatorname{Cov}`、概率 `\mathbb P`。
- 向量矩阵用粗体 `\boldsymbol`，转置统一 `^\top`。
- **LaTeX 控制词后若紧跟字母必须加空格**：写 `\to A`、`\le x`，不可写 `\toA`、`\lex`。
- 禁止 TODO、占位内容、对话式表达、表情符号、Obsidian 语法。

## 六、完成后报告（从简）

只回报：输出路径、写出的 `## n.` 小标题数量、该章习题数（并确认二者相等）。不要贴正文。


## 红线补充（务必遵守，违反会被退回重写）

1. **证毕符**：证明结束必须写**独占一行**的字面 `□`（前面留一个空行）。**禁止**写成 `$\square$`、`\square`、`\blacksquare`，也禁止接在句子末尾（如「……成立。□」）。
2. **术语**：一律写全称「几乎必然」。**禁止** `a.s.`、`a.e.`、「几乎处处」等缩写或变体。同理写「几乎 surely」的混用也不允许。
3. **数学环境内不得出现中文字符**（包括 `\text{...}` 内）。需要中文限定语时，把它写在公式**外面**的散文里。例如不要写 `X=Y\quad\text{a.s.}`，而应写公式 `$$X=Y$$` 后接一行「几乎必然成立。」
4. **控制词后接字母必须留空格**：`\to A`（不是 `\toA`）、`\le 0`、`\mathbb E`。
5. 转置写 `^\top`；期望 `\mathbb E`；概率 `\mathbb P`；方差 `\operatorname{Var}`；协方差 `\operatorname{Cov}`；σ-代数 `\mathcal F`／`\mathcal G`；向量与矩阵用 `\boldsymbol`。
