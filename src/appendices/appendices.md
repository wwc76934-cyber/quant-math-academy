# 附录 A　常用数学符号

| 符号 | 含义 |
|---|---|
| $\mathbb N,\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ | 自然数、整数、有理数、实数与复数集合 |
| $\forall,\exists,\exists!$ | 对任意、存在、存在且唯一 |
| $\neg,\land,\lor,\Rightarrow,\Leftrightarrow$ | 否定、合取、析取、蕴含与等价 |
| $\sup A,\inf A$ | 集合 $A$ 的上确界与下确界 |
| $\boldsymbol x^\top,\boldsymbol A^\top$ | 向量或矩阵的转置 |
| $\operatorname{rank}(\boldsymbol A)$ | 矩阵的秩 |
| $\lambda_{\min}(\boldsymbol A),\lambda_{\max}(\boldsymbol A)$ | 对称矩阵的最小与最大特征值 |
| $\boldsymbol A\succ0,\boldsymbol A\succeq0$ | 正定与半正定 |
| $(\Omega,\mathcal F,\mathbb P)$ | 概率空间 |
| $\mathbf 1_A$ | 事件或集合 $A$ 的指示函数 |
| $\mathbb E[X],\operatorname{Var}(X),\operatorname{Cov}(X,Y)$ | 期望、方差与协方差 |
| $\mathbb E[X\mid\mathcal G]$ | 给定子 $\sigma$-代数 $\mathcal G$ 的条件期望 |
| $\xrightarrow{\mathbb P},\xrightarrow{d},\xrightarrow{a.s.}$ | 依概率、依分布与几乎必然收敛 |
| $\nabla f,\nabla^2f$ | 梯度与 Hessian |
| $\partial f$ | 次微分；具体语境中也可表示偏导，由上下文区分 |
| $\mathcal N(\mu,\sigma^2)$ | 均值为 $\mu$、方差为 $\sigma^2$ 的一维正态分布 |
| $(W_t)_{t\geq0}$ | 标准 Brown 运动 |
| $[X]_t$ | 过程 $X$ 在时刻 $t$ 的二次变差 |
| $\operatorname{ARMA}(p,q)$ | 阶数为 $(p,q)$ 的自回归移动平均模型 |
| $\operatorname{IC},\operatorname{RankIC}$ | 信息系数与秩信息系数 |
| $\operatorname{VaR}_\alpha,\operatorname{ES}_\alpha$ | 水平 $\alpha$ 下的风险价值与期望损失；具体符号方向见第三十二章 |
