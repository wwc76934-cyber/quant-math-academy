# 前言

量化研究以数学模型为语言，以数据为证据，以计算方法为实现手段。随着统计学习、自动化交易和金融工程的发展，量化研究者所需接触的数学领域不断扩展。然而，知识的扩展并不必然带来理解的加深。公式可以被快速检索，软件可以迅速给出数值结果，但模型为何这样建立、结论在何种条件下成立、估计误差如何传播、研究方法何时失效，仍然只能依靠扎实的数学训练作出判断。

本书面向已经学习过高等数学、线性代数、概率论与数理统计，并希望系统进入量化研究、金融工程或相关数据科学领域的读者。全书不以罗列面试公式为目的，而是围绕数学概念的形成、理论结论的推导及其适用边界组织内容。量化金融问题在书中承担两种作用：一是为抽象数学提供有实际背景的问题来源，二是检验读者能否把数学理论转化为严谨的研究方法。金融应用不构成削弱证明与理论分析的理由。

全书共八篇三十四章。前三篇依次建立分析、线性代数与概率论基础；第四篇讨论凸优化和数值计算；第五篇进入数理统计、回归与统计学习；第六篇研究随机过程和随机分析；第七篇讨论时间序列；第八篇将前述理论综合运用于因子研究、投资组合、衍生品定价和研究考核。这样的安排旨在保持知识依赖关系的连续性。例如，正交投影既是最小二乘的几何基础，也是理解条件期望和 Kalman 滤波的重要工具；条件期望既连接概率论与统计预测，也是鞅论和风险中性定价的核心概念。

书中对重要定义、定理、命题和例题采用统一编号。定理证明力求给出关键中间步骤，并明确所需假设。对于超出本书范围的测度论或泛函分析结果，会清楚区分定理陈述、证明思路和完整证明，避免以形式化符号代替严格论证。每章末尾设有习题，书后提供相应参考答案与解析。习题既包括概念辨析和常规计算，也包括证明、综合推导及适量量化研究问题。

阅读本书时，读者不必以相同速度学习所有章节。具有大学数学基础的读者可以通过章首内容和例题判断自己需要复习的部分；以量化研究实习为目标者，应优先掌握概率、统计、矩阵分析、优化和时间序列；以衍生品定价或连续时间金融为目标者，则需在具备概率论和鞅论基础后进入随机微积分。数学能力的形成依赖主动推导和独立解题，而不是对公式的被动浏览。

本书为教学工作而编写。书中涉及的模型和案例用于说明数学方法，不构成任何投资建议。真实市场研究还需要考虑数据质量、交易成本、市场冲击、制度约束和模型风险，这些因素不能由单一数学公式替代。
